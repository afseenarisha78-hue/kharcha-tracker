# Kharcha Tracker 

A lightweight, mobile-friendly web app designed to track daily commute, coaching, and personal expenses in Taka (৳) without needing an account or internet connection after loading.

**Live App:** [https://github.io](https://github.io)

## Features
- **Starting Balance & Chacha Rate:** Set your initial budget and standard per-trip fare once at the start.
- **Pending Balance Management:** Track unpaid amounts from previous days and choose whether to deduct them from today's starting money or keep them separate.
- **Daily Expense Categories:**
  - **Transport:** Add multiple fares one by one throughout the day.
  - **Chacha & Coaching:** Count coaching trips automatically and log any extra route fares.
  - **Extra Spent:** Record personal expenses separately from commute costs.
- **Date-by-Date History:** View, edit, or reset saved entries for any day, stored privately in your browser.

##  Built With
- HTML, CSS, and JavaScript (Single-file web app)
- Browser `localStorage` for offline data persistence
